# 🛒 SwiftCart E-commerce Platform

A full-stack E-commerce web application built using Spring Boot that enables users to browse products, manage cart, and perform secure checkout with role-based access control.

---

## 🚀 Key Features

✔ Product Catalog with Category-Based Filtering  
✔ Advanced Search Functionality  
✔ Stock-Aware Cart Management  
✔ Multi-Step Checkout Workflow  
✔ Secure Authentication & Authorization  
✔ Role-Based Access (Customer, Seller, Admin)  
✔ Order Tracking System  
✔ Admin Dashboard for Product & Inventory Management  
✔ Dynamic Category Management (Add / Update / Delete)  
✔ Online Payment Integration + Cash on Delivery  

---

## 🔐 Security Implementation

- Spring Security integration  
- Role-based access control (RBAC)  
- BCrypt password encryption  
- Token-based email verification  

---

## 🛠 Tech Stack

- Java  
- Spring Boot  
- Spring Security  
- Thymeleaf  
- Hibernate / JPA  
- MySQL  
- HTML, CSS, JavaScript  

---

## 🗄 Database Design

Entities Used:

- User  
- Product  
- Category  
- Cart  
- Order  
- OrderItem  

---

## ⚙ How to Run the Project

1. Clone the repository  
2. Configure MySQL database in `application.properties`  
3. Run the Spring Boot application  
4. Open in browser: http://localhost:8080
